# 나라장터 용역 입찰공고 수집기

공고 게시일 범위를 지정해 조달청 나라장터 용역 입찰공고 API를 조회하고, 공개 상세 페이지를 브라우저로 읽어 로컬 JSON에 저장하는 Next.js 앱입니다. 저장된 공고는 목록과 상세 화면에서 확인할 수 있습니다.

상세 화면의 **수집 데이터 비교**에서는 API 공고 항목 전체와 나라장터 상세 페이지에서 추출한 필드·본문·첨부파일·링크를 좌우로 확인할 수 있습니다. 비어 있는 API 값도 표시하며, 각 칸의 JSON 원문을 펼쳐 볼 수 있습니다.

## 시작

1. Node.js와 Google Chrome을 설치합니다.
2. `npm install`을 실행합니다.
3. [`.env.local`](.env.local)의 `G2B_SERVICE_KEY=` 뒤에 공공데이터포털에서 발급받은 나라장터 입찰공고정보서비스 인증키를 입력합니다. 일반 인증키와 URL 인코딩된 인증키를 모두 사용할 수 있습니다. `.env`도 사용할 수 있지만 `.env.local`에 같은 변수가 있으면 그 값이 우선합니다. 두 파일 모두 Git에서 제외됩니다.
4. `npm run dev`를 실행하고 `http://localhost:3000`을 엽니다.
5. 웹 화면에서 **공고 게시일**의 시작일과 종료일을 선택해 `공고 수집 시작`을 누릅니다. 두 날짜 모두 조회 범위에 포함됩니다.

Chrome이 기본 설치 위치에 없으면 `.env.local`에 `G2B_CHROME_PATH=Chrome 실행 파일의 절대 경로`를 추가합니다.

## 저장 위치

- `data/api/<작업 ID>/`: API 호출별 전체 JSON 응답
- `data/notices/`: 공고번호와 공고차수 조합별 API 원본 항목, 상세 페이지 추출 결과, 화면용 데이터
- `data/jobs/`: 수집 진행 상태와 오류

`data/`는 Git에서 제외됩니다. 한 번에 한 수집 작업을 실행합니다. 개별 상세 페이지 수집에 실패해도 해당 공고의 API 응답은 저장하고 화면에 실패 상태를 표시합니다.

## 검증

```powershell
npm test -- --run
npx tsc --noEmit
npm run build
```

실제 API와 공개 상세 페이지 한 건을 확인하려면 네트워크 접근이 가능한 환경에서 다음을 실행합니다.

```powershell
$env:LIVE_G2B='1'
npm test -- --run src/lib/g2b/api-client.live.test.ts src/lib/g2b/detail-page.live.test.ts
```

인증키를 입력한 뒤에는 짧은 날짜 범위를 수집해 목록·상세 화면과 첨부파일 다운로드를 확인하세요.

## 첫 버전의 범위

용역 공고만 수집합니다. 첨부 문서 본문 분석, 자동 갱신, 개인별 입찰 적합성 판정, 데이터베이스는 포함하지 않습니다. 화면의 `정보 없음`은 수집한 API와 공개 상세 페이지에서 해당 값을 확인하지 못했다는 뜻입니다. 최종 참가 조건과 제출 내용은 나라장터 원문 및 첨부파일을 확인하세요.
